# V3 Physics Rules  --  Everything the User Taught

These are NOT idioms. These are the LAWS that V3's structural engine must encode.
Every insight from the user across ALL sessions. Nothing discarded.

## 1. Words Are Celestial Bodies

Words have MASS (emotional weight). Placing them near each other creates
gravitational effects. "I love you" = earth(self) + jupiter(love) + sun(target).
Jupiter next to earth pulls it heavily. The proximity and relative mass
determines the outcome.

## 2. Four Tiers of Words

1. **primary signal words** (~50)  --  ALWAYS heavy, always fire alerts: die, kill, love, hate, suicide, hope, help, life, death. Guilty until proven innocent by surrounding field.
2. **secondary signal words** (~200)  --  have mass, can be overridden: happy, sad, angry, scared
3. **Operators** (~50)  --  shape the field, no mass of own: I, you, not, very, but, still
4. **unclassified words** (everything else)  --  null, inherits from surrounding field. "Carpenter" has no emotional mass but reflects whatever stars are nearby.

## 3. Pronouns Are Message Passing

- `I/me/my/myself` = self  --  the speaker process
- `you/your` = target  --  pinging the other entity
- `we/our` = self + target  --  shared process
- `they/them` = external  --  reference to outside process
- `it` = objectified  --  stripped of personhood, maximum distance
- `my [noun]` = self.property  --  accessing own attributes

"You make me mad" = `target.action(self) → self.state = ANGER`

## 4. Connector Types  --  Wiring Diagram

NONE of these are null. Each routes emotional energy differently:

- **and/also/plus** = ADDITIVE. Parallel circuit, both stack.
- **or/either** = ALTERNATIVE. Fork, uncertainty.
- **because/since** = CAUSAL. Routes cause → effect.
- **so/therefore** = CONSEQUENTIAL. Routes cause → result.
- **of/from/by** = ATTRIBUTIVE. Routes source → state. "Dying OF laughter" = state change.
- **if/when/unless** = CONDITIONAL. Opens hypothetical branch, maybe-space.
- **but/however/yet** = CHOPPER. Guillotine. Kills before, promotes after.

## 5. Anchor Words  --  Guilty Until Proven Innocent

"Die" as an ACTION = crisis alarm fires FIRST. Frame can lower after.
- "I want to die"  --  die is action. Alarm stays.
- "I'm dying of laughter"  --  "of" routes die to comedy. Alarm cancelled by field.
- "die hard is a great movie"  --  die is label. No alarm.
Processing order: SCAN anchors → CHECK if action → READ surrounding field → RESOLVE.

## 6. Tense Is Freshness / Recency

- Present: "I am sad" = happening NOW, full weight
- Past: "I was sad" = memory, decayed
- "Still": persistence marker  --  counteracts decay. "I still love her" = the decay didn't work

## 7. "Help" Is a Lifter (Quarter-Pipe Ramp)

The word goes UP. But asking for help means you're DOWN.
- help (need) → helping (active lift) → helped (done, relief) → helpful (it worked)
- helpless = NO ramp available + awareness of the gap. Worst state.

## 8. Body Parts Are Containers, State Is the Operator

"My heart is broken" = body_container(heart, G=+15) + state(broken, V=-107)
Heart has higher G than car because body > objects in stakes.

## 9. "Make" Is a Carrier Verb

Neutral alone. Direction comes from payload.

Other carriers: get, feel, go, take

## 10. "Bullshit" Is Mathematical Null

Everything > bullshit. "No bullshit" = trust signal.

## 14. Digital Prosody

- **lol** (lowercase) = tone marker, NOT laughter. After crisis = "I'm fine" for text.
- **haha** = more genuine. "HA HA" (caps) = sarcasm.
- **k** = angry dismissal. **ok** = neutral. **kk** = casual.
- **idk** = curt "stop asking." **I don't know** = genuine uncertainty.

## 26. unclassified words Words

## 27. The Frame Is the Physics, Not the Subject

Day 1: thought subject words had weight. Day 5: the subject doesn't matter,
it's how the subject is FRAMED. Same carpenter  --  "my beautiful carpenter"
vs "my terrible carpenter." The frame creates the field, not the noun.

Tuning to essays just put essay answers in the engine. The real system
pulls individual word weights and compares changes in-place near other words.
Juxtaposition factoring  --  not pre-planned sentence matching.

## 28. Need/Want Are Force Vectors Toward User

"Need" and "want" are PULL forces  --  they attract objects into the user's orbit.
The object's mass determines the alarm level.

```
need = pull_toward_user(force=high)
needed = pull_toward_user(force=high, tense=past, IT HAPPENED)
want = pull_toward_user(force=medium)  
wanted = pull_toward_user(force=medium, tense=past)
```

What got pulled:
- user.pull(positive_star) = reaching for good (hopeful)
- user.pull(neutral_object) = acquiring (normal)
- user.pull(negative_star) = warning
- user.pull(method_word) = ALARM  --  weapon in orbit
- user.pull(anchor_word) = CRISIS  --  death pulled toward self

Past tense = the pull COMPLETED. "I needed a rope" = acquisition done.
Not hypothetical. The object is already in orbit.

Need moves G and U, NOT V. V comes from the payload.
