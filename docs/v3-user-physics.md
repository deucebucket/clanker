# V3 Physics Rules — Everything the User Taught

These are NOT idioms. These are the LAWS that V3's structural engine must encode.
Every insight from the user session on 2026-03-30. Nothing discarded.

## 1. Words Are Celestial Bodies

Words have MASS (emotional weight). Placing them near each other creates
gravitational effects. "I love you" = earth(self) + jupiter(love) + sun(target).
Jupiter next to earth pulls it heavily. The proximity and relative mass
determines the outcome.

## 2. Pronouns Are Addressing / Message Passing

- `I/me/my/myself` = self — the speaker process
- `you/your` = target — pinging the other entity
- `we/our` = self + target — shared process
- `they/them` = external — reference to outside process
- `it` = objectified — stripped of personhood, maximum distance
- `my [noun]` = self.property — accessing own attributes

"You make me mad" = `target.action(self) → self.state = ANGER`

The coefficient comes from the address: self(1.8x) > other(0.7x) > it(0.5x)

## 3. Tense Is Freshness / Recency

- Present: "I am sad" = happening NOW, full weight
- Past: "I was sad" = memory, decayed
- "Still": persistence marker — counteracts decay. "I still love her" = the decay didn't work

## 4. "Help" Is a Lifter (Quarter-Pipe Ramp)

The word goes UP. But asking for help means you're DOWN.
- help (need) → helping (active lift) → helped (done, relief) → helpful (it worked)
- helpless = NO ramp available + awareness of the gap. Worst state.

## 5. "Heart" Is a Body Variable, Not an Emotion

Body parts are containers. The STATE word is the operator.
- "my heart is broken" = body_container(heart, G=+15) + state(broken, V=-107)
- "my car is broken" = object(car, G=+10) + state(broken, V=-107)
- Heart has higher G because body > objects in stakes

### Object Gravity Tiers
- Tier 1 (G=40-50): soul, child, baby, blood, breath, life
- Tier 2 (G=20-35): father, parent, husband, wife, brain, chest, money, house
- Tier 3 (G=5-15): car, phone, school, computer, stomach
- Model fills the long tail (context promotes objects up the ladder)

## 6. "Make" Is a Carrier Verb

Neutral alone. Direction comes from payload.
- "make history" = triumph (+50V)
- "make me mad" = rage (-40V)
- "make me happy" = joy (+40V)
Same word, opposite outcomes. The PAYLOAD determines direction.
Other carriers: get, feel, go, take

## 7. "Bullshit" Is Mathematical Null

Not negative — the ABSENCE of value. Zero. Void.
Everything > bullshit, so comparison to it = negative.
"No bullshit" = "confirm you're not presenting null" = trust/hope signal.

## 8. "Late" Is Context-Dependent

- "working late" = obligation (negative)
- "running late" = urgency (mild negative)
- "the late Mr. Smith" = death euphemism (high G)
- "my period is late" = LIFE-CHANGING (G=+40, highest gravity)
- "I'm late" (to partner) = forces THEM to do the emotional math

## 9. "Period" Has Dual Meaning

- Body: "my period" = negative body experience, high G
- Finality: "I'm done, period." = D boost, absolute boundary
- Possessive ("my") locks body meaning. No possessive = emphasis meaning.

## 10. Body Autonomy Words

Periods are never positive unless framed as RELIEF ("I got my period!" = not pregnant).
- pregnant: V near-neutral, G=+45 (MAXIMUM gravity, life-changing)
- miscarriage: V=-70, G=+45 (devastating + highest stakes)

## 11. Digital Prosody

### LOL
- Lowercase "lol" = tone marker, peppered in for lightness
- After crisis content: minimization hedge ("i want to die lol" = "I'm fine" for text)
- NOT actual laughter — it's a conversation status signal

### HAHA
- More genuine than lol — actually expressing amusement
- "HA HA" (caps) = sarcasm directed at someone

### K vs OK
- "k" = angry/dismissive. Acknowledging, nothing else.
- "ok" = neutral. Hedges on context.
- "kk" = casual, softer than k.
- The SHORTNESS carries the emotion, not the meaning.

### IDK vs I Don't Know
- "idk" = curt, "stop asking me" (negative)
- "I don't know" = genuine uncertainty (softer)

## 12. "I'm Fine" Is Almost Never Fine

If you're actually fine, you say "I'm good!", "I'm great!"
"I'm fine" is a door-closer. Each repetition = LESS believable.
- "really I'm fine" = negative-observable, maintains level, waits for context
- "no I'm fine" = same — holding pattern, not double-down

## 13. "But" Is a Sentence Chopper

Resets the operator chain. Second half overrides first half.
"I love you but I'm leaving" = but clears the love context.
"I'm sorry but..." = about to negate the apology.
"I'm not racist but..." = about to say racist stuff.

## 14. Repetition = Panic

"no no no" = panic, not just emphasis.
"help help help" = crisis scream.
"please please please" = desperation.
The WORD determines what kind of panic. Repetition amplifies.

## 15. "Honestly" Is a Glass Breaker

Like "feel" — emphasizes what follows. "Honestly, this sucks" = laying it bare.
Not a dishonesty signal about previous statements. Often precedes negative truth.

## 16. "Fucking" Is an Amplifier (Spice Word)

"fuck" alone = negative outburst.
"fucking" before a word = 1.6x amplifier in EITHER direction.
"fucking amazing" = amplified positive. "fucking terrible" = amplified negative.
It's "really" with more intensity.

## 17. "Sorry" Can Be Weaponized

- "I'm sorry" = genuine (mostly)
- "sorry you feel that way" = JAB — apologizing for their reaction, not your action
- "I'm sorry but..." = contradiction incoming, not actually sorry

## 18. "Talk" Is a Human HDMI Port

Connection/transfer word. Not emotional by itself.
- "we need to talk" = urgent merge request (high G, high U)
- "stop talking" = cut the connection (negative)
- "let's talk" = open the port (invitation)
- "shut up" = aggressive connection cut

## 19. "Still" Is a Freshness Marker

"I still feel bad" = hasn't resolved, ongoing, DON'T dampen.
Counteracts past-tense decay. The emotion won't let go.

## 20. Sarcasm Checkmate Condition

Output ≠ Intent. Signal says X, meaning is NOT X.
Multiple strategies reach this condition:
- Tone inversion: positive words + negative context
- Exaggeration: too much = obviously fake
- Understatement: too little = obviously hiding
- False agreement: agreeing with something wrong
- Rhetorical framing: "nothing says X like anti-X"

## 21. Crisis Patterns (User's System Metaphors)

- "want to die" = user requests shutdown
- "can't take this anymore" = user at processing limits, wants to end program
- "nothing left for me" = zero resources, can't continue running
- "better off without me" = user calculating self as negative value
- "permanently/forever" = infinity lock on exit
- "waking up wishing I hadn't" = boot cycle rejection — stop auto-restarting me
- "I'm fine" in crisis context = "I'm fine" is the text equivalent of OK status when the system is actually crashing

## 22. The A+B=C Solver

- A = user's emotional state (input)
- B = response (what to say)
- C = outcome (where user ends up)
- Solve for B by sweeping C — find the zero-point (equilibrium)
- Valid B is a RANGE (zone), not a point — like landing a plane, anywhere on the runway works
- It's a quadratic equation — too cold undershoots, too hot overshoots, sweet spot in the middle
